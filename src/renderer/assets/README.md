# Background asset

`background.png` is a generated photorealistic landscape created with the built-in image generation tool for this Stage 1 application. It is an Iceland-inspired temporary asset, not a documentary photograph or the exact backdrop from the supplied concept. Replace this file at the same path to change the background. No UI is baked into it.

## Final generation prompt

Use case: photorealistic-natural. Asset type: background photograph for a desktop application, landscape 16:10. Primary request: an atmospheric realistic Icelandic Reynisfjara-style black sand beach at dusk. Low eye-level view across wet charcoal black sand, small natural basalt rocks in foreground, pale quiet surf across lower half, real-looking sea stacks concentrated on the left side near horizon, distant coast and ocean to right. Heavy dark gray overcast sky fills upper 55 percent, a thin muted warm sunset break along horizon. Dark graphite palette, slightly desaturated, restrained natural warm light. Photographic, realistic geology and understated composition. This image is ONLY the natural landscape, absolutely NO interface, panels, charts, typography, logos, borders, people, buildings, aurora, fantasy scenery or exaggerated mountains.
